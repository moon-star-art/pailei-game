## 下载到本地游玩

点击右侧 **Code → Download ZIP** 下载解压，由于游戏基于现代浏览器模块化脚本，直接双击 `index.html` 可能被浏览器安全策略拦截，请用任一静态服务器托管本目录后访问，例如：

```bash
# 方式一：Python
python -m http.server 8080

# 方式二：Node.js
npx serve .
```

然后浏览器打开 <http://localhost:8080>。

## 游戏特色

- 🏰 据点攻防：占领中立据点、扩张版图，直捣敌方大本营
- 🃏 手牌即军队：52 张扑克牌作为兵牌，编排出战顺序，同色比大、异色比小
- 🏳️ 国家篇：执掌五方势力之一，金币买兵、建造经营（金锋 / 赤焰 / 苍岚已开放战役）
- 🌳 政策树：用对局奖励的政策点逐节点解锁被动增益与战术
- 🤝 云端联机：创建房间与好友远程对局（官方链接内可用）
- 🎲 每局随机：开局手牌随机、守方迎战顺序随机且保密
- 🤖 蒙特卡洛胜率采样 AI，三档进攻倾向
- 🎓 新手教学：固定牌面教学关 + 分步引导，约两分钟上手
- 📱 手机浏览器亦可游玩（横屏体验最佳）
- 🎵 8 首 CC0 民谣风 BGM 随机连播 + 全套操作音效
